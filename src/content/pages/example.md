## An editable page

This page lives at `src/content/pages/example.md` and renders at
`/pages/example/`. Unlike the block-composed pages (home, about, services),
these are simple long-form markdown pages — good for privacy policies, terms,
or any prose content.

Edit this in TinaCMS: run `npm run dev` and open `/admin`.
